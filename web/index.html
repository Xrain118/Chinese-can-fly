运动控制台

按 1 → 4 设置；SPEED 是唯一的基础速度入口
1选择运行模式
直接模式

直接模式：PWM/MOVE 可独立设置左右轮，SPEED 仍会同时设置左右轮。

2设置基础速度
唯一速度入口
0400 / 10001000

SPEED 在任意模式下设置左右同值 PWM，并在 START 后恢复。

3选择速度执行方式
ENC OFF

ENC ON：目标 CPS 由 SPEED、模式和满量程 CPS 自动换算，速度 PI 只修正最终 PWM。

4启动或停车
自动下发 SPEED 后启动

编码器闭环参数

下面参数用于左右轮速度 PI 和同步修正，不会改变基础控制模式。

日常试车优先使用上方 1 → 4 控制台

左右侧速度 PI（共享参数）

左右各运行一个 PI，反馈值分别取同侧前后轮平均 CPS
ENC OFF 正在生效
同侧两台电机共用 PWM，前后轮 CPS 仅用于求平均和诊断，不能通过本控制器单独调平。只有上方选择“编码器闭环”时 Kp/Ki 才参与输出。
试运行建议 先架空车轮，刷新并确认参数；校准“满量程 CPS”后再启用。若方向异常或振荡，立即旁路速度环。
